MyHobby 改良版
=============
既存リポジトリの同じ場所にある2ファイルを、このフォルダーのファイルで置き換えてください。
- pages/index.vue
- layouts/default.vue

変更内容
- トップページとスマートフォン向けレイアウト
- 商品名による検索、検索結果がない場合の案内
- 使い方別の購入前チェックポイント
- 広告表記、掲載方針、ページタイトル・説明・canonical
- 未確認の価格表示と予算別分類を削除
- 楽天アフィリエイトのリンク8件と画像URLを保持

確認状況
- git diff --check 実行済み。
- リンク8件の保持を照合済み。
- この作業環境にはnpmがなく、Nuxtビルド・ブラウザー確認は未実施。
- 商品の価格・在庫・詳細仕様・外部画像の表示は未確認。
- GitHubへの反映および本番公開は未実施。

公開前
Nuxtの開発環境で依存ライブラリをインストールし、npm run build を実行してください。
検索、スマホ表示、楽天リンク先、画像の表示を確認してください。
今後、検証済みの商品情報と実体験に基づく個別記事を追加できます。
